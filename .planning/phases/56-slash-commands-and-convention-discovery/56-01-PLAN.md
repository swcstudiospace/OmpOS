## Not built in this phase

- Discovery for cloud sessions: no cloud-session discovery source exists in the tree; the desktop palette of a cloud agent has no convention source.
- Discovered commands, skills and subagents in the web palette (`WebSessionControls` passes `SlashDiscovery.Empty`).
- A file watcher: discovery runs at session start and again at most every 5 s when the palette opens.
- The workspace conventions panel (`WorkspaceConventionsView`) is not moved to `ConventionCatalog`; the SlashDiscovery report says it still reads only `.autonogrammer` (not re-checked in the tree).
