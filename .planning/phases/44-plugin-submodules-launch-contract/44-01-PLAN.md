## Amendments after the first build

- `SWARM_GSD_STATE_FILE` is no longer empty. Phase 48 (commit `5a2a224`) made it a per-session path `<session>/swarm/gsd-state.md`, because the pseudo-terminal backend removes a variable whose value is empty, which would let the swarm write `swarm:` lines into the workspace `.planning/STATE.md`. Decision D44-3 and criterion 5 are amended accordingly (see `44-CONTEXT.md`).
- The planner also sets `AUTONOGRAMMER_STEER_DIR` and `AUTONOGRAMMER_CONNECTION_FILE` for every session (Phase 48).
- D44-8 (the planner also plans terminal launches) was built in Phase 48: `OmpLaunchPlan.ForTerminal`.
