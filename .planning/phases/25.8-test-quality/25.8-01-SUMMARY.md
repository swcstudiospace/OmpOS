## Observations (production, not changed)

- `SandboxStatus.Provisioning` and `SandboxStatus.Degraded` are never assigned by any production code path. The enum documents states that no code produces. The new totality test records this. Owner decision: assign them, or remove them from the enum.
- The `FlushAsync` barrier is a best available barrier, not a proof: the row's settlement continuation runs on the thread pool and exposes no completion signal. The fault test gets a positive signal from the trace line, which precedes only the (guarded) post. The non-fault test waits for the model change and then flushes. A guard regression that posts late enough to miss three pool round trips would still pass; no production hook exists to close that gap.
