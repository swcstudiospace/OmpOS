# Phase 51 Plan 01: Brand, Theme and Licence

Inputs: ROADMAP.md Phase 51 (criteria 1 to 4), REQUIREMENTS.md (PX-01 to PX-04), `docs/plans/v0.15.0-research/` (brand and licence research), `docs/open-questions.md` OQ-93 (licence reading), OQ-94 (Light default), OQ-62 (closed by ADR-0018), `docs/decisions/ADR-0018-licence-agpl-and-source-offer.md`.

This record lists the units that were built, from the commits and the tree. It was written after the work and is not a plan that was followed in advance. The work was done by separate builders (brand set, licence files, desktop brand wiring, API source endpoint, web head) and landed in the commits below; the wave commits (`wip(f2b)`, `wip(f3a)`) carry several units at once.
