<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Desktop head process (AgentHead/CoworkHead) → ComputerUse L2 | Untrusted model output and screen frames cross into policy gate; only granted apps visible. |
| Local approval dialog → gate | User decision (host-observed facts only) vs agent request; security phrase prevents spoof. |
| Kill switch hotkey / indicator → executor | External OS event or pointer takeover must reliably revoke without race. |
| Audit log (owner-only JSONL on disk) | Tamper or loss must be detectable (prev hash) or deny action. |
| Dispatch origin (via 74) → local grant | Remote command can only queue; local user must still approve; grants time-boxed and visible in indicator. |

## STRIDE Threat Register (updated for wiring gap closure; original in ADR-0035)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-73-01 | Spoofing / Tampering | Approval dialog + indicator | high | mitigate | Host-observed facts only (D-12), security phrase, Deny default, no auto-allow, 120s timeout, own-window hard deny + mask, serialised execution. |
| T-73-02 | Tampering / Elevation | Injection without ticket or while prompt open | critical | mitigate | Single-use ticket bound to action hash (IComputerActionGate), executor is ONLY caller of InjectAsync (ComputerUseBoundaryTests), process-wide lock, re-resolve window after move. (Duplicate ID fixed by this plan referencing only 73-02 core.) |
| T-73-03 | Denial of Service | Kill switch unavailable or taken | high | mitigate | Registration verified before first action and before arming (KillSwitchCoordinator + backend), separate thread/conn, three Stop paths, token checked between primitives, gate denies when indicator absent. |
| T-73-04 | Information Disclosure | Screen frames or typed text to model / log | high | mitigate | Masking (VisibleRegionMasker on granted only), no typed text/clipboard bytes in audit, credential titles always ask, thumbnails redacted by default, frames stay on desktop except to user's chosen provider. |
| T-73-05 | Tampering | Audit log tampering or loss | medium | mitigate | Owner-only 0600/ACL, append-only FileShare.Read, write-ahead before injection + deny on failure, SHA-256 prev chain (genesis recorded), daily rotation, 30d retention. |
| T-73-06 | Spoofing | App identity on X11 / window move | medium | mitigate | Prefer /proc/<pid>/exe + WM_CLASS, re-resolve after pointer move before button, abort on change, denylist wins, own process never granted. |
| T-73-07 | Elevation via remote | Dispatch hijack of desktop | critical | mitigate | No `computer.*` relay op (R1 + ADR-0036), computer_use only as toolClass on cowork.task, local-only approvals (MustBeLocal=true), 30m Dispatch grants, per-device opt-in + AllowDispatchSessions=false default, indicator shows controller device. |
| T-73-SC | Supply Chain | Any new native or NuGet | high | mitigate | No new package (enforced by licence gate + notices check in criterion 6); P/Invoke only to system libs already present on host (X11 exemplar in PosixProcessSignal). |

All threats from ADR-0035 table are covered by the existing 01-06 code; this plan adds only the production seam and asserts the mitigations are reached from the live head path.
</threat_model>
