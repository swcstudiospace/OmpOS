## Open items

- OPEN, M-4 detached path: no test. A fault after the row has detached was not traced in the harness. The first test drove it with `ApprovalRemove`, and the cause was not isolated (the coordinator rethrows bridge faults, and `Decide` traces them; the test's listener never received the trace). The test was removed rather than kept unproven. Next step: isolate whether removal cancels the pending call, then either drive a detach that keeps the approval, or accept the code path by review.
- OPEN, desktop logger gap: the native composition passes no logger, so the services' new ILogger output (M-2, M-3, M-17, M-19) is discarded in the desktop app. Only the API and web hosts log those faults. Owner decision needed: wire an `ILoggerFactory` into the desktop composition (a change in the composition root), or accept that desktop service faults stay silent. ADR-0011 records this as a known gap.
- Not tested: D10 (the stderr drain failure, Debug log). The stderr pipe failure cannot be forced deterministically from a real child.
- Not closed: D4 scope. A compensation failure that is neither `HerdrSessionException` nor `OperationCanceledException` still escapes and replaces the original persist failure, as before. Widening the catch was not in the accepted criteria.
- Chosen: D9 exemption. A session-initiated close does not log an error when the pump exits, so normal disposal stays quiet.
