## Decisions the units recorded

- `SshAcpTransport` does not wrap `AcpStdioTransport` (that class puts `acp` first and takes a local working directory); the container and WSL transports reuse it through an internal `ExecTransportFlavor` (RemoteCore decision 1, RemoteContainers decision 2).
- Secrets travel in a stdin preamble, written by the remote shell to a mode 600 file, sourced and removed; they are never an argument (ADR-0015 D3). `SendEnv=-*` is not passed because OpenSSH 9.6 does not honour it on the command line.
- Plugins are not copied to the remote host: map or drop with a Degraded stage; the owner can install them by hand (ADR-0015 D6, default taken).
- Containers and WSL carry no reverse forwards (`CarryLoopbackServices=false`); a loopback MCP server stays and is reported as probably unreachable.
- A container is never started by preflight; `Start container` is a user action and only when the last test found it stopped.
