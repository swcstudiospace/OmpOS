## Not built in this phase

- A client that produces the consent snapshot for a cloud agent: no code outside the worker mentions the `ompos_hooks_consent` claim.
- The worker image does not carry the extension (`deploy/worker.Containerfile` has no `ompos-hooks-omp` line and no `Worker__Hooks__*` setting), and nothing is deployed to Railway.
- Hook files of a remote ssh host are not read; no bridge and no extension run on the remote host (`SessionEngineSet.StartHooksAsync`: `NoHookFiles`, `hookBridge = extras.IsRemote ? null : hooks?.Endpoint`).
- Hosted API: the web Hooks page lists hook files (`HooksReader`, `HooksListPage`); the hook run events are not pushed into the web run stream from the API (no use of `HookRunRecordProjector` outside `OmpOS.Harness.AgentLoop` and the worker).
