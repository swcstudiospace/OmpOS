# Phase 66.3 Summary: Web accessibility (WCAG 2.2 AA)

Status (recorded 2026-10-29): Complete with caveats. The scripted checks ran against the built Demo bundle and the built real bundle; the web smoke of the final commit passed with every accessibility group on both halves and zero error findings. Nine defects of the web head that the first runs found are fixed, a tenth (F10) that a screenshot showed is fixed, and the checks' own false findings were corrected with self-tests. The target is WCAG 2.2 level AA; the statement says "partially conformant" because no screen reader, no real device, no Windows High Contrast theme and no browser other than Chrome was available. The desktop head is out of scope (OQ-179).

The record was written after the work. Statuses use: Met, Met (recorded), Partial, Blocked, Not verified.

## What changed in the product

| Defect | Fix |
|--------|-----|
| F1 The route announcer said nothing or the previous title | `RouteAnnouncer.Arm(destination)` runs before the view changes |
| F2 Scrollable code, tool output and file-edit text took focus with no name | Focusable groups with a name |
| F3 Titles were clamped or cut: text spacing hid words | They wrap |
| F4 The composer's focus was a colour change | The card takes the two-pixel ring |
| F5 On a short screen the drawer was as tall as its content | It has the height between the top bar and the footer and scrolls |
| F6 "Jump to latest" vanished while focused and dropped the focus | It stays while focused and hands focus to the transcript |
| F7 After choosing an agent the focus call ran before the render | The call follows the render |
| F8 axe could only say "needs review" for `aria-controls` next to `aria-haspopup` | The chips and the textarea set neither |
| F9 Forced colours: a primary button's highlight fill hid its label | A thicker highlight border and no fill (see the open item below) |
| F10 The close control of a selected agent row covered the end of its time (24 by 10 px measured); found in a screenshot, not by a check | The title line of the selected row leaves the room of the control (`rail.css`); measured with the rule on the real bundle: no overlap, the row keeps its height. No check compares the boxes of two controls (K14) |

Other changes: `a11y.css` (forced colours, increased contrast, 24 px targets, reflow, text spacing), persistent live regions, `RouteFocus`, and the scripted checks in `scripts/web-smoke/a11y/` wired into the web smoke.
