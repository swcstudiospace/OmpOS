# Phase 66.3 Context: Web accessibility (WCAG 2.2 AA)

Milestone v0.16.0, inserted after Phase 66.2 on 2026-10-29. Requirements AG-AX-1 to AG-AX-8. Documents: `docs/accessibility/` (statement, criteria table, keyboard script, screen-reader plan, known issues). Checks: `scripts/web-smoke/a11y/`.

## What this phase does

The owner asked for a fully working and *accessible* web application. This phase brings the web head to WCAG 2.2 level AA as far as a self-assessment without assistive technology can, records exactly how far that is, and puts the checks in the smoke so that a regression fails the gate.

## Decisions

| ID | Decision | Evidence |
|----|----------|----------|
| D66.3-1 | Scope is the web head (`apps/Autonogrammer.Web`, `src/Autonogrammer.UI`, `src/Autonogrammer.Presentation`) and the in-browser Demo. The desktop head has its own checks and is out of scope; the gap is recorded (OQ-179). | `docs/accessibility/statement.md` |
| D66.3-2 | The evidence is: axe-core 4.14.0 (pinned and hash-checked) on every route and reachable state; scripted checks for what axe cannot decide (titles, headings, landmarks, route announcements, keyboard walk, focus visibility and obscuring, dialogs, reflow, text spacing, target size, forced colors, increased contrast, reduced motion); code review; unit tests of names, live regions and contrast pairs. A screen reader, other browsers, a phone and users with disabilities are not part of it. | `docs/accessibility/wcag-2.2-conformance.md`, `screen-reader-test-plan.md` |
| D66.3-3 | `a11y.css` adapts and never redesigns: it is imported last, changes no colour token value, and adds forced-colors, `prefers-contrast`, scroll padding, 24 px targets, reflow at 560 and 360 px and text-spacing support. | `src/Autonogrammer.UI/wwwroot/styles/a11y.css`; `Autonogrammer.UI.Tests` style tests |
| D66.3-4 | Focus moves to the page heading after a navigation, never on the first page that renders, so the skip link stays the first Tab stop (criterion 2.4.1). | `RouteFocus.razor`, `RouteFocusTests` |
| D66.3-5 | The transcript uses progressive disclosure instead of virtualization so every rendered turn stays in the accessibility tree and in find-in-page; announcements of streamed text are batched. | `SessionView.razor`, `TranscriptAnnouncements` |
| D66.3-6 | The statement says "partially conformant" until a recorded run of the scripted checks and a screen-reader pass exist; it never claims conformance that was not observed. | `docs/accessibility/statement.md` |
