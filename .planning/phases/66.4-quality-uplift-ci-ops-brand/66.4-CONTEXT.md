# Phase 66.4 Context: Quality uplift: CI, supply chain, operations and brand

Milestone v0.16.0, inserted after Phase 66.3 on 2026-10-29. Requirements AG-QU-1 to AG-QU-8. Documents: `docs/security/hosted-threat-model.md`, `docs/privacy/data-retention.md`, `docs/runbooks/{slo-and-alerting,incident-response,backup-and-restore,deploy-and-rollback}.md`, `deploy/railway/README.md`, `docs/brand.md`.

## What this phase does

The owner asked for state-of-the-art, best-in-class, production-ready and enterprise-grade quality. The code and the pipeline were already strict (warnings are errors, `AnalysisLevel` is `latest-all`, locked restores, a 12215-test gate). The gaps were around the code: no software bill of materials, base images pinned by tag only, no least-privilege or timeout settings in CI, no gate for skipped tests or for breaking API changes, no threat model, retention policy, SLOs or incident and recovery runbooks for a hosted deployment, and a wordmark that the rename tool had broken into "Autonogrammer" without its two-colour split.

## Decisions

| ID | Decision | Evidence |
|----|----------|----------|
| D66.4-1 | No package is added. The SBOM is generated from the committed lock files and package metadata by a script, so it can be checked and cannot drift silently. | `scripts/legal/generate-sbom.py`, `docs/legal/sbom.spdx.json`, `scripts/ci/check-sbom.sh` |
| D66.4-2 | Base images are pinned as `tag@sha256`, the runtime images have a `HEALTHCHECK`, and `scripts/ci/scan-images.sh` runs a scan when `trivy` is installed and says so when it is not. It has not run: neither `trivy` nor an image build ran on this host. | `deploy/api.Containerfile`, `deploy/worker.Containerfile`; OQ-175, OQ-177 |
| D66.4-3 | The CodeQL, Scorecard and artifact-attestation workflows are written with SHA-pinned actions and have never run; the Omega runners may not reach those services (OQ-175). `ci.yml` gains job timeouts and least permissions. | `.github/workflows/*` |
| D66.4-4 | A skipped test needs a suppression row, and the OpenAPI document may not lose or narrow a route silently. Both are gates of `repo-checks.sh`. | `scripts/ci/check-skip-markers.sh`, `scripts/ci/check-openapi-breaking.py` |
| D66.4-5 | The operations documents state proposals, not measurements: SLO targets have no data behind them (OQ-180) and no alert is wired. They say what to measure and what to do. | `docs/runbooks/slo-and-alerting.md` |
| D66.4-6 | Railway Config as Code is deprecated for new services, so `deploy/railway/*.railway.json` are reference files only (OQ-181). | `deploy/railway/README.md` |
| D66.4-7 | The wordmark has "Auto" in the text colour and "nogrammer" in the accent colour; the SVG sources were re-fitted and every asset regenerated. The owner has not signed off the logo or the trademark. | `assets/brand/`, `docs/brand.md`; `bash scripts/ci/check-brand.sh` |
| D66.4-8 | Tests written for this milestone follow the same analyzer rules as the product code, with no `#pragma` and no `SuppressMessage`. A test that skips on a platform has a SUP row. | SUP-237 to SUP-239 |
