# Phase 68 validation map

Every AG-68 id to its proving test, command, wave and Live gate. All commands run with
`cd /root/src/repos/ompos-autonogrammer` through the serialising wrapper `/tmp/ag-bin/ag-dotnet`
(never bare `dotnet`); every container-backed command uses the status-preserving shape
`source "$(bash scripts/test-services.sh up)" && { /tmp/ag-bin/ag-dotnet test ...; rc=$?; bash scripts/test-services.sh down; exit $rc; }`
so a failed `up` ends nonzero before any test runs and `down` still runs when the test fails
(a trailing `; down` would return down's status and mask red tests). MTP syntax follows the repo
convention: `-- --filter-class "*FooTests*"`, `-- --filter-not-trait "Category=Live"`,
`-- --filter-trait "Category=Live"`. Nothing deploys to Railway (OQ-73); no Railway mutation.
ROADMAP success criteria 1 (build + locked restore + licence check) and 2 (whole Linux set on
throwaway services) are owned by 68-07's final phase-gate task, run once after all other plans land.
