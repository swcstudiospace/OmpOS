# Phase 25.3 Context: Bounded Child and Vendor Reads (fix F-B)

Source: 25.1-FINDINGS.md section 4 (H-2), section 5 (M-1, M-5, M-6, M-7). The owner accepted all eight fix phases on 2026-10-26; F-B runs second.

## Decisions

- D1 (H-2, ACP stdout): one bounded line reader in OmpOS.Harness.Abstractions, the project both OmpOS.Harness.Acp and OmpOS.Harness.Rpc reference. Its limit is 1 MiB characters, the same limit the RPC transport enforces (OmpRpcFrames.MaxPhysicalLineContentBytes, OmpRpcProcess.cs:114). Exceeding it throws MalformedFrameHarnessException with the message "A physical frame exceeds the 1 MiB transport limit." (the RPC message). The ACP transport then fails the session through its existing exit path.
- D2 (M-1, remote frames): OmpOS.EngineHost reads SSE lines through the same bounded reader and caps accumulated frame data at the same 1 MiB. Exceeding throws MalformedFrameHarnessException. The silent transport-drop break at RemoteEngineHost.cs:347 is not changed here; it belongs to F-D (M-2).
- D3 (M-5, omp version probe): OmpOS.Harness.Rpc/OmpVersionProbe.cs caps captured stdout at 4096 characters, the limit the launcher probe already uses (OmpOS.Harness.OmpLauncher/OmpVersionProbe.cs:15). On overflow the probe kills the child and fails with the same exception type the launcher probe uses. The agent reads that file and mirrors it; no new convention.
- D4 (M-6, M-7, vendor responses): OmpOS.Sandbox.Abstractions gains one bounded-content helper with a 4 MiB limit. AgentOsProvider and RailwaySwarmProvider read response bodies through it and throw their existing vendor-error exception on overflow. Reason for 4 MiB: vendor JSON responses are small; the limit bounds memory without affecting a normal response.
- Recorded duplication: the web head's BoundedContent (added in Phase 25.2) and this helper have the same shape. They are not shared, because OmpOS.Web does not reference the sandbox or harness layers and a shared project would add a new project with its own lock file. This is a known gap for a later consolidation.

## Assumptions

- Phase 25.2 is green at its own HEAD before this phase starts.
- Subagents edit files only; the lead runs the single gate.
