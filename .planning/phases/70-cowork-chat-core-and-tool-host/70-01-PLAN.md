<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Model text to tool arguments | A model-supplied argument named origin is ignored; origin comes only from the lease set by the chat core. |
| Tool result to session trust | The first IsUntrusted block permanently taints the session; taint is host state no result can clear. |
| Audit file to tamperer | Owner-only hash-chained JSONL; truncation or edit of a prefix is detectable on read. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-70-01-01 | Spoofing | CoworkToolHost origin | high | mitigate | Ignore model-supplied origin argument; lease SetTurnOrigin only from chat core; test asserts it. |
| T-70-01-02 | Tampering | FileCoworkToolAudit | medium | mitigate | Hash chain with prev SHA-256 per line; write failure never fails the call; tamper-detection test. |
| T-70-01-03 | Elevation | CoworkPolicyGate grants | high | mitigate | Grants satisfy ByPolicy only, never EveryCall variants or Destructive; AllowedAlways only; taint overrides grants. |
| T-70-01-04 | Information disclosure | Audit entries | medium | mitigate | Entries hold no arguments and no result bytes; provider exceptions logged without arguments. |
| T-70-01-05 | Denial of service | Result caps | medium | mitigate | Text 65536, 2 images 3 MiB each 6 MiB total, 256 KiB arguments, 120 s timeouts, one call per session. |
</threat_model>
