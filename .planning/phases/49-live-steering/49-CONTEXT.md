# Phase 49 Context: Live Steering

Milestone v0.14.0. Requirements AL-15, AL-16. Depends on Phases 46 and 48 (the Kanban card entry point also needs Phase 39). Decision records: ROADMAP.md DR-4, `docs/open-questions.md` OQ-81 (the mechanism), OQ-66 and OQ-59 (Substrate and the earlier queue-after-turn default), `docs/decisions/ADR-0012-agent-loop-plugins.md` (Update 2026-10-26, implementation). Evidence: `docs/runbooks/evidence/phase-48-omp-plugins-2026-10-26/acp-auth-and-steering.md`.

This context was written after the work (2026-10-26) from the commits `16488c5` feat(49-01) and `0a5d03e` fix(49-02), the earlier inbox work of `5a2a224`, `3050a71` and `8dd0f0b`, the code, the tests and the evidence files. It records what was decided in the code, not a discussion. The first of the two Phase 49 commits was committed uncompiled and was verified by the second.

## Goal

A running session takes a steering message from the Agent Panel composer and from its Kanban card, the session visibly takes it into account before the turn ends, delivery is reported truthfully, and a steer that cannot be delivered fails without changing the session (DR-4, AL-15, AL-16).

Success criteria are in `.planning/ROADMAP.md` (Phase 49, criteria 1 to 5). The criteria table with status is in `49-SUMMARY.md`.

## DR-4 as built

DR-4 said that prompting over ACP cannot deliver live (a new `session/prompt` cancels the running turn) and that Substrate on the pinned commit has no live delivery, so the mechanism was an open question (OQ-81) with the omp extension inbox as the default. The build found a better path in the installed omp 18.12.6, and the inbox became the second mechanism.

## Open questions

- OQ-81: the mechanism. Default in force: native `_session/steering` for chats, the inbox for terminals and as fallback. `injected` into a running turn is not verified (needs a model turn, OD-07).
- OQ-66: Substrate Phase 53 live delivery; Autonogrammer does not depend on it.

## Known limits

- `_session/steering` is an omp extension request that exists in omp 18.12.6; an older omp falls back to the inbox.
- Delivery by the inbox needs the `gsd-core-omp` plugin running inside that omp; a heartbeat older than 15 seconds refuses the directive.
- The steering history entries are kept by `SteeringInputModel.History` (capped at 100); no view lists them in this commit (see `49-SUMMARY.md`).
