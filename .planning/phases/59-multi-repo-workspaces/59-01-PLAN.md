- A head path that creates a `WorktreeRunSet` for a run: `WorktreeRunSet` is referenced from `apps/OmpOS.Native/Settings/WorktreesSettingsSource.cs` for its `DefaultMaxWorktrees` constant only; no session start calls `CreateAsync`.
- Convention merge across roots in a head: `SessionEngineSet.SlashDiscoveryFor` and `ConventionSettingsLoader` pass the primary root only.
- A set with roots in different environments (the validator refuses it) and a live run of a remote set with `--add-dir` on the remote host.
- A model turn with additional directories (OD-07).
