Status: implemented, gate pending (2026-10-26). Nothing in this phase has been built or tested yet: the implementing agent did not run the build, the tests or the formatter. The lead runs the gate and replaces this line with the commit and the result.

## Success criteria

1. AgentOsProvider refuses a non-loopback cleartext origin at construction and sends its token only to the configured origin. Implemented. `AgentOsOriginTests` (not run): refusal of `http://api.rivet.dev`, `http://203.0.113.9`, `ftp://localhost`; acceptance of https, localhost, 127.0.0.1, [::1]; a 307 is refused with only one request sent; a response from another origin is refused; the factory client does not contact a redirect target (real loopback listeners).
2. Compose files are owner-only. Implemented. `ComposeFileModeTests` (not run): file 0600 and directory 0700 on Unix, removed on teardown and on failed provision.
3. Setup steps run only after per-repository consent keyed by path and file hash. Implemented. `SetupRunnerConsentTests` and `FileSetupConsentStoreTests` (not run) cover refusal without consent, run after consent, no second prompt while unchanged, re-prompt after a change, per-repository keys, the exact-bytes hash, environment-only setups, an approval that cannot be saved, and a corrupt, empty, null-grants, unmapped-member or unknown-version store (quarantined, never throws).
4. The gate is green at the phase HEAD. Pending.
