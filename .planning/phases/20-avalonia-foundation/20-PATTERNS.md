## Shared patterns

### A. csproj shape

- Product library (plain): `src/OmpOS.GenUi/OmpOS.GenUi.csproj:1-7`. `Microsoft.NET.Sdk`, one `ProjectReference` to Contracts. Use this shape for `OmpOS.Presentation`.
- Razor library: `src/OmpOS.UI/OmpOS.UI.csproj:1-17`. `Microsoft.NET.Sdk.Razor`, `SupportedPlatform browser` (line 5), `PackageReference` with no version (9-10), `ProjectReference` (14-15).
- Exe: `tests/OmpOS.Sessions.Postgres.Probe/OmpOS.Sessions.Postgres.Probe.csproj:3-6` (`OutputType Exe`, `IsPackable false`). Use this for `OmpOS.Native`, with a `ProjectReference` to Presentation.
- Shared settings (inherited, do not repeat in new csproj files): `Directory.Build.props:3` (`net10.0`), `:4` (`LangVersion latest`), `:5` (`Nullable enable`), `:6` (`ImplicitUsings enable`), `:7` (`TreatWarningsAsErrors true`), `:9` (`AnalysisLevel latest-all`), `:12` (`GenerateDocumentationFile true`, so every public member needs a `/// <summary>`, or CS1591 fails the build), `:13` (`JsonSerializerIsReflectionEnabledByDefault false`), `:15` (`CentralPackageTransitivePinningEnabled true`), `:16` (`RestorePackagesWithLockFile true`), `:20` (`IsTrimmable true`). `:23-26` set `RestoreLockedMode` on CI.
- Test projects get test props by name (`Directory.Build.props:29-35`, `$(MSBuildProjectName.EndsWith('Tests'))`). New `*.Tests` projects inherit them.
- `BannedSymbols.txt` applies to every project (`Directory.Build.props:38`). `BannedSymbols.NoProcess.txt` (`:39`) also applies to `OmpOS.Native` and `OmpOS.Presentation`, because their names do not start with `OmpOS.Harness.` and are not `OmpOS.Sandbox` or `*Tests`.
- Every new project commits its `packages.lock.json` (D-20-12). Existing projects each carry one, for example `tests/OmpOS.UI.Tests/packages.lock.json`.
- MAUI pins are kept in the app csproj, not central (`apps/OmpOS.App/OmpOS.App.csproj`, `ItemGroup Label="Workload package pins"`). Avalonia is a normal NuGet package, so its pins go in `Directory.Packages.props` (see C), following the `Blazor shells` group.

### B. Test shape

- File-scoped namespace, `public sealed class`, `[Fact]` or `[Theory]` with `[InlineData]`, Shouldly assertions. Examples: `tests/OmpOS.Contracts.Tests/ContractVersionTests.cs:5-33`, `tests/OmpOS.UI.Tests/SessionScrollTests.cs:7-17`.
- Each test has a `/// <summary>` that cites its requirement ID. Existing tests use `UI-01` to `UI-04` and `IN-01`. New tests should cite `XP-01`, `XP-08` and `XP-09`, per `20-CONTEXT.md`.
- Each test project refs the exact subset it needs. `bunit` only appears in `tests/OmpOS.UI.Tests/OmpOS.UI.Tests.csproj:7` and `tests/OmpOS.Web.Tests`. Do not add it to Native or Presentation tests.
- Synthetic-violation proofs are the repo pattern for gates: `tests/OmpOS.ArchitectureTests/ProjectGraphTests.cs:43-51` and `ArchUnitLayerTests.cs:39-52`. Copy this for the no-UI-framework contract tests.
