# Phase 20 — UI Design Contract

> Visual and interaction contract for the Avalonia native head shell (`apps/Autonogrammer.Native`, Avalonia 12.1.4). Scope is the Phase 20 shell only. Locked decisions D-20-01 to D-20-14 in `20-CONTEXT.md` are inputs, not re-decided here. Generated by gsd-ui-researcher; verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | Avalonia 12.1.4 built-in controls. Base theme: Avalonia.Themes.Fluent 12.1.4 (D-20-06). Every colour, type and spacing value is read from the Phase 20 token dictionary (D-20-07). |
| Icon library | none. Two inline path geometries: send glyph `M3 3.5 21 12 3 20.5 7 12Z` (same path as `src/Autonogrammer.UI/Components/Composer.razor`) and stop glyph (filled square). |

The Component Inventory section is omitted because Tool is `none`. The shared control set is fixed in "Control Inventory" below.

## Scope of the Phase 20 Surface

- One main window, title `Autonogrammer`. No dialogs, no second window.
- Two columns:
  - Left: session list, fixed width 240 px.
  - Right: transcript region (fills the remaining width), then a status line, then the composer row (prompt input, send, stop).
- Phase 20 renders only the states it can produce: list loading, list empty, list failed, transcript loading, transcript empty, transcript failed, plus the idle composer. Approvals, streaming output, reconnecting, offline, retry and jump-to-latest belong to Phase 21 and have no visible surface in this phase.

## Control Inventory and Accessible Names

Every control sets `AutomationProperties.Name` explicitly (D-20-09). Names are chosen here, and the AT-SPI2 evidence in the runbook must show them.

| # | Control | Avalonia element | AutomationProperties.Name | Tab stop | Notes |
|---|---------|------------------|---------------------------|----------|-------|
| 1 | Session list | `ListBox` in the left column | `Conversations` | 1 | Each row sets its own Name to the full session title. |
| 2 | Transcript region | `ScrollViewer` around the transcript content | `Session transcript` | 2 | `Focusable="True"` and `IsTabStop="True"` are set in XAML. See Open Items. |
| 3 | Prompt input | `TextBox`, `AcceptsReturn="True"`, `TextWrapping="Wrap"` | `Message` | 3 | Placeholder `Type a message…`. Name matches the web Composer. |
| 4 | Send | `Button`, 44×44 px, send glyph | `Send message` | 4 | Icon only, so the Name is required. |
| 5 | Stop | `Button`, 44×44 px, stop glyph | `Stop response` | 5 | Icon only, so the Name is required. Always enabled (see Behaviour). |
| 6 | Status line | `TextBlock` with `AutomationProperties.LiveSetting="Polite"` | `Session status` | not a tab stop | Non-control live region. Named so the AT-SPI2 output identifies it. |

Keyboard order is XAML and logical-tree order: session list, transcript, prompt input, send, stop. The window itself has no Name beyond its title.

## Behaviour Contract

| Input | Condition | Result |
|-------|-----------|--------|
| Enter | Prompt focused, no Shift | Send command. Blank or whitespace-only draft: no-op; draft and focus unchanged. Non-blank draft: see the refused-send row. |
| Shift+Enter | Prompt focused | Inserts a newline (`AcceptsReturn`). |
| Send (click or Enter on the button) | Non-blank draft | Host refuses in Phase 20 (no transport). Draft is kept. Status line shows `Message not sent. Sending is unavailable.` |
| Escape | Prompt focused and a response is running | Stop command. Phase 20 never has a running response, so Escape has no effect. Mirrors `Composer.razor`. |
| Stop (click or Enter on the button) | No running response | No-op. Status line shows `No response is running.` The control stays enabled. |

The draft clears only when the host accepts the send, matching `Composer.razor`.

## Keyboard and Focus

- Focus indicator: a `:focus-visible` style on `ListBox`, `ListBoxItem`, the transcript `ScrollViewer`, `TextBox` and `Button`.
  - `BorderBrush` = `Autonogrammer.Color.Accent`.
  - `BorderThickness` = `Autonogrammer.Size.FocusBorder` (2 px).
  - `FocusAdorner` = null on each of those controls, so no default ring is drawn alongside the token ring (D-20-10).
- The focus colour is the Accent token. It is in the contrast table against all three backgrounds, so it stays visible on the transcript (Background), the list and composer (Surface) and a selected or hovered row (SurfaceActive).
- No Phase 20 shared control is disabled, so no focusable control is removed from the tab order.

---

## Motion

- `MotionPreference` (presentation layer): `System`, `Reduced`, `Full`.
- `System` resolves to `Full` on Avalonia 12.1.4, because no OS reduced-motion reader exists (AvaloniaUI/Avalonia#19405). Recorded in Open Items (D-20-08).
- `Reduced`: the root `Window` gets the class `reduced-motion`. A style under `Window.reduced-motion` sets `Transitions` to an empty collection on every shared control listed in the Control Inventory.
- The only non-essential animation in Phase 20 is the `Button` background colour change on hover and press: `BrushTransition` on `Background`, 120 ms, `Full` mode only. Nothing else animates. The loading states are static text with no spinner.

## Color

| Role | Token | Value | Usage |
|------|-------|-------|-------|
| Dominant (60%) | `Autonogrammer.Color.Background` | #ffffff | Window, transcript, prompt input, Button default background |
| Secondary (30%) | `Autonogrammer.Color.Surface` | #f4f4f5 | Session list column, composer row |
| Surface active | `Autonogrammer.Color.SurfaceActive` | #e4e4e7 | Button hover and pressed background; selected session row background |
| Text | `Autonogrammer.Color.Text` | #1a1a1a | Body text, prompt input text, Button labels, Stop glyph |
| Muted text | `Autonogrammer.Color.TextMuted` | #52525b | Prompt placeholder, status line, 1 px control borders, empty-state body text |
| Accent (10%) | `Autonogrammer.Color.Accent` | #0b4fd6 | Focus ring on every shared control, Send glyph, 2 px left bar on the selected session row |
| Error | `Autonogrammer.Color.Error` | #b3261e | Failed-state heading and body in the list and transcript panes |

Accent reserved for: the focus ring, the Send glyph, and the selected-row bar. It is never a button fill, a heading colour or a body-text colour. Destructive: none in Phase 20 (no destructive action exists; Stop is not destructive). The Error token is used for error copy only.

Accent is used only as a foreground (text, glyph or border), never as a background, so every colour pair is covered by the contrast table below.

### Contrast contract (every foreground × every background)

The contract test enumerates every foreground token against every background token in `Autonogrammer.Tokens.axaml` and asserts at least 4.5:1. The ratios below were computed with the WCAG 2.x relative-luminance formula on 2026-10-21. The test recomputes them and is the source of truth.

Background tokens: `Background`, `Surface`, `SurfaceActive`. Foreground tokens: `Text`, `TextMuted`, `Accent`, `Error`. Twelve pairs:

| Foreground | Background | Ratio | Required | Result |
|------------|------------|-------|----------|--------|
| Text #1a1a1a | Background #ffffff | 17.40 | 4.5 | pass |
| Text #1a1a1a | Surface #f4f4f5 | 15.83 | 4.5 | pass |
| Text #1a1a1a | SurfaceActive #e4e4e7 | 13.72 | 4.5 | pass |
| TextMuted #52525b | Background #ffffff | 7.73 | 4.5 | pass |
| TextMuted #52525b | Surface #f4f4f5 | 7.03 | 4.5 | pass |
| TextMuted #52525b | SurfaceActive #e4e4e7 | 6.09 | 4.5 | pass |
| Accent #0b4fd6 | Background #ffffff | 6.77 | 4.5 | pass |
| Accent #0b4fd6 | Surface #f4f4f5 | 6.16 | 4.5 | pass |
| Accent #0b4fd6 | SurfaceActive #e4e4e7 | 5.33 | 4.5 | pass |
| Error #b3261e | Background #ffffff | 6.54 | 4.5 | pass |
| Error #b3261e | Surface #f4f4f5 | 5.95 | 4.5 | pass |
| Error #b3261e | SurfaceActive #e4e4e7 | 5.15 | 4.5 | pass |

Minimum 5.15:1 (Error on SurfaceActive). No other token is defined. Adding a token means adding every new pair to this table and to the test.

## Claude's Discretion

Design choices the locked decisions left open. Each has a one-line reason.

1. **Native accent `#0b4fd6` (web primary is `#0b5fff`).** `#0b5fff` measures 4.04:1 on `SurfaceActive`, under the 4.5:1 contract. The native head uses Accent as text and focus colour on that background.
2. **Stop always enabled.** A disabled control leaves the tab order, which would break the keyboard-order and reachability contract for Stop. Its command is a no-op with a status message when nothing runs.
3. **Send always enabled; blank send is a no-op.** Same reason as Stop. Gating stays in the presentation view model, which the web head shares.
4. **Single light theme.** Matches the web head. A dark theme doubles the pair count and no Phase 20 criterion needs it.
5. **Fixed 240 px session list, no breakpoints.** The brief allows only the window minimum; a fixed width keeps the layout deterministic.
6. **Window MinWidth 640, MinHeight 480; initial size 960×640.** The list, the transcript and two 44 px buttons need the width; 480 keeps the composer visible.
7. **One Button transition (120 ms background).** Gives the reduced-motion test a real transition to remove. No other animation keeps the reduced path small.
8. **Error copy `Close and reopen Autonogrammer to try again.`** Phase 20 has no retry control, so the copy must name a path the user can take. Product review may change the wording.
9. **Names `Conversations`, `Session transcript`, `Session status`.** `Message`, `Send message` and `Stop response` are reused from the web Composer so AT output matches across heads. `Conversations` matches the web nav label. `Session transcript` avoids the generic `Session` section name used by the web head.
10. **No bundled font.** The system stack avoids a new package, and no package is invented.
11. **Icons as inline geometry.** Two glyphs do not justify an icon package.
12. **Refused-send status line.** Phase 20 has no transport. The draft must not be lost and the user must see why nothing happened.
13. **A new session-list load-state enum in presentation code.** The list needs loading and failed states that the web list does not have.
14. **Escape mirrors the web Composer.** It stops only while a response runs.
15. **Status line visible, not only announced.** Refusal and stop-idle messages must be seen, not just spoken.
16. **Token names use the `Autonogrammer.Color|Font|Space|Size.*` prefix.** One naming scheme across the dictionary and the contract test.
