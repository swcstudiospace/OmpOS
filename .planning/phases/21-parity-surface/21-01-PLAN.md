# Phase 21, Plan 01: Compose the Production Engine for Approvals and Sends

Goal: close Phase 21 criterion 4 ("Approve or deny reaches the ACP permission bridge") on the production native head. Criterion 5 is out of scope.
Decisions and sources: `21-CONTEXT.md`.

## Tasks

1. **Compose the production engine at launch, lazily.** `Program.Main` builds the app over `ComposeProductionEngine`, which composes `EngineComposition.Compose(ProductionAllowedKinds)`, with `ProductionAllowedKinds` empty (deny by default).
   - Files: `apps/OmpOS.Native/Program.cs`, `apps/OmpOS.Native/Engine/EngineComposition.cs` (optional `transportFactory`; `Resolver` exposed on the record).
   - Verify: `ProductionEngineComposesOnTheFirstDecisionAndDeniesEveryKind`.

2. **Share one lazy engine between approvals and sends.** `App(Lazy<EngineComposition>)` passes the lazy engine to `MainWindow`, which creates `EnginePromptChannel` over it. The unused `App(EngineComposition)` overload is removed.
   - Files: `apps/OmpOS.Native/App.axaml.cs`, `apps/OmpOS.Native/MainWindow.axaml.cs`, `apps/OmpOS.Native/Engine/EnginePromptChannel.cs` (new).
   - Verify: `TheFirstSendComposesTheEngineAndLaunchComposesNothing`.

3. **Connect the composer send and stop to the host.** `StartTurnAsync` streams the turn in the background and clears the draft once the host accepts it. `StopTurnAsync` cancels the in-flight turn. Without an engine, sends are refused as before.
   - Files: `apps/OmpOS.Native/MainWindow.axaml.cs`.
   - Verify: `ASendSubmitsThePromptThroughTheComposedHostAndStreamsTheReply`, `StopCancelsTheInFlightTurnThroughTheHost`.

4. **Stream turn events into the transcript and show failures inline.** `ShowTurnEvent` folds each event through `OmpOS.Sessions.HarnessEventProjection` into `SessionViewModel`. Host exceptions become `ErrorEvent`s.
   - Files: `apps/OmpOS.Native/MainWindow.axaml.cs`, `apps/OmpOS.Native/OmpOS.Native.csproj` (project reference to `OmpOS.Sessions`).
   - Verify: `ASendThatFailsShowsItsReasonInlineInTheTranscript`.

5. **Park host permission requests in the approval UI.** A `PermissionRequestEvent` becomes a `PendingToolApproval` row keyed by `RequestId ?? CallId`, the key the resolver parks under. Deny and approve use the existing coordinator and bridge.
   - Files: `apps/OmpOS.Native/MainWindow.axaml.cs`.
   - Verify: `AParkedHostPermissionRequestAppearsInTheApprovalUi`, `DenyingAParkedHostPermissionRequestSettlesItDenied`, `ApproveUnderDenyAllReportsRefusedAndLeavesTheParkedRequestPending`.

6. **Close the host on window close.** `MainWindow.OnClosed` disposes the channel, which disposes the host only when it was composed.
   - Files: `apps/OmpOS.Native/MainWindow.axaml.cs`, `apps/OmpOS.Native/Engine/EnginePromptChannel.cs`.

7. **Test support.** A scripted `omp acp` peer and an in-memory ACP transport, so no live omp runs.
   - Files: `tests/OmpOS.Native.Tests/Send/ScriptedAgent.cs`, `tests/OmpOS.Native.Tests/Send/ScriptedAgentTransport.cs`, `tests/OmpOS.Native.Tests/Send/EngineSendPathTests.cs`.

8. **Records.** `21-CONTEXT.md`, this plan, and `21-SUMMARY.md` (criterion 4 Met with evidence; criterion 5 Open).

Not changed: `RunInputScheduler`, `IRunInput`, `UnconnectedRunInput`, `ComposerView.SteerDraftAsync` (steering, criterion 5). Nothing under `src/OmpOS.Harness.*`.

## Verification commands

Run from the repository root. Set the .NET environment first, because the default SDK is 8.0:

```
export DOTNET_ROOT=/root/.dotnet DOTNET_NOLOGO=1 DOTNET_CLI_TELEMETRY_OPTOUT=1; export PATH=/root/.dotnet:$PATH
```

Restore is needed once after the project reference was added. `CI=true` is set in this environment, so the lock file must be updated explicitly:

```
/root/.dotnet/dotnet restore tests/OmpOS.Native.Tests/OmpOS.Native.Tests.csproj -p:RestoreLockedMode=false --force-evaluate
```

Build, with zero warnings required:

```
/root/.dotnet/dotnet build apps/OmpOS.Native/OmpOS.Native.csproj -c Release --no-restore
/root/.dotnet/dotnet build tests/OmpOS.Native.Tests/OmpOS.Native.Tests.csproj -c Release --no-restore
```

Tests, excluding live traits:

```
/root/.dotnet/dotnet test tests/OmpOS.Native.Tests/OmpOS.Native.Tests.csproj -c Release --no-build -- --filter-not-trait "Category=Live"
/root/.dotnet/dotnet test tests/OmpOS.Native.Tests/OmpOS.Native.Tests.csproj -c Release --no-build -- --filter-class "*EngineSendPathTests*"
```

Subagents do not run `bootstrap.sh` or `dotnet format`. The parent runs the full gate after this unit.
