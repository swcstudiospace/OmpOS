## Decisions the units recorded

- The catalogue is data (JSON), not C#: about a hundred rows are one-line diffs and the generator script reads the same files. Each route names one of the omp api values; the writer maps all 13 omp values (ten documented plus `openrouter-decisions`, `openai-decisions`, `workers-ai-systemone`).
- A model list is declared (`discovery`) only where the research documents the list route as fact; a route with no list and no documented model asks the user for a model id.
- Mistral is three rows (api, Codestral, Vibe plan); Anthropic's subscription is a sign-in-only row (`/login anthropic`, never stored); Cloudflare Workers AI has its own row id `cloudflare-workers-ai-compat` because a block under omp's id lists as kind `judge`.
- Not offered (ADR-0019 table): GitHub Models, Lambda, Replicate, 01.AI Yi, Qwen Portal OAuth, DeepL, BFL, Teuken, Poro, Kyutai, Fraunhofer, watsonx, cursor, resellers, and Cerebras Code and Ollama plans as rows.
- The hosted API never stores a provider key: only an omp-native row without URL variables is keyed (`omp auth import`); any other row answers 409 `credential_operator_managed` naming an environment variable (OQ-104).
- Coding plans are bring-your-own-key with the vendor's rule text and a tick; cloud agents default to pay-as-you-go keys (OQ-98).
