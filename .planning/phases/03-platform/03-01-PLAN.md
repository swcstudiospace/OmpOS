# Phase 3 · Plan 01 — Sandbox abstraction, lifecycle, fake + podman-compose providers, typed vendor stubs (SBOX-01..05)

## Objective

`ISandboxProvider` with explicit timeouts/idempotency keys, lifecycle guarantees (TTL, reaper, retried teardown, never-left-Running), fake + local podman-compose providers under a contract fixture, typed vendor stubs with golden policy files, and explicit isolation defaults.

## Contracts (existing)

`SandboxDescriptor`, `SandboxStatus` (Requested, Provisioning, Ready, Attached, Degraded, TearingDown, Destroyed, Failed), `Isolation`, `Attestation` in src/OmpOS.Sandbox.Abstractions' sibling Contracts project. Wire facts: `.planning/phases/03-platform/03-RESEARCH.md` VF-1..VF-3, VF-5 (authoritative).

## Tasks

1. `src/OmpOS.Sandbox.Abstractions`: `ISandboxProvider` — `Task<SandboxDescriptor> ProvisionAsync(ProvisionRequest request, CancellationToken)` (request carries `IdempotencyKey`, `SessionId`, bounded `Timeout`, `SandboxSpec`), `Task AttachAsync(string sandboxId, ...)`, `Task<int> ExecAsync(string sandboxId, IReadOnlyList<string> argv, ...)`, `IAsyncEnumerable<string> StreamLogsAsync(string sandboxId, ...)`, `Task<byte[]?> SnapshotAsync(string sandboxId, ...)` (returns null + `NotSupportedException`-typed result where unsupported), `Task TeardownAsync(string sandboxId, CancellationToken)`; `SandboxCapability` record describing `Isolation`, `Attestation`, `NativeBinaries` surfaced on the descriptor.
2. `SandboxLifecycle` (src/OmpOS.Sandbox): wraps any provider; ctor `(ISandboxProvider, TimeProvider, SandboxLifecycleOptions{Ttl, TeardownRetryCount, BaseBackoff})`; provisions register in a registry keyed by sandboxId + session; `ReapOrphansAsync()` tears down entries past TTL or whose session is not Running; teardown retried with **jittered exponential backoff** (jitter from injected `Random`); `ProvisionAsync` failure guarantees the session is never observed Running (integration point: throws before status flip — tested via a fake clock sequence).
3. `FakeSandboxProvider`: deterministic in-memory; configurable failure injection (fail provision N times, fail teardown M times); passes the contract fixture.
4. `IProcessRunner` (`Task<ProcessResult> RunAsync(ProcessSpec, CancellationToken)` with argv-only, no shell) + `LocalPodmanComposeProvider`: builds compose file content from a typed model into a temp file, runs `podman-compose -f <file> up -d` / `podman ps --filter label=ompos.session=<id>` / `podman-compose ... down`; labels every resource `ompos.session=<id>` + `ompos.sandbox=<id>`; real invocation behind the injectable runner (fake runner in tests; a `[SkippableFact]` smoke runs `podman-compose config` for real, skipped when podman absent — podman 4.9.3 IS present here, do not skip locally).
5. Vendor stubs, all interface-conforming, ZERO invented vendor calls: `OpenShellProvider` (checks host prerequisites via IProcessRunner: `podman --version` ≥ 5, cgroups v2, user socket; returns typed `PrerequisiteMissingResult` when unmet — true on this host, podman 4.9.3; golden-tests the gateway TOML + policy YAML v1 it WOULD generate from `OpenShellPolicyModel` with `landlock.compatibility: hard_requirement`), `AgentOsProvider` (typed `NotAvailable`, open question Q-SB-AGENTOS), `RailwaySwarmProvider` (typed `NotAvailable`, `Attestation: None`, Q-SB-RAILWAY), `AttestedEnclaveProvider` (dstack-shaped `IAttestationBoundary { GetQuoteAsync(nonce) }` returning `Unverified` — never `true`; Q-SB-ENCLAVE). SnapshotAsync → typed unsupported result on every stub (v2 deferral, per 03-RESEARCH scope note). Add the three open-question rows to `docs/open-questions.md` matching the table format (ID | Question | Why it matters | Default taken | Owner | Status).
6. `SandboxProviderOptions` (isolation defaults, SBOX-05): `NoHostMounts=true`, `NoHostSecrets=true`, `PerSandboxCredentials=true`, `OutboundNetworkDefaultDeny=true`; every provider consults them; a canary test provisions via Fake+Podman providers and asserts descriptors, log strings, and (for workflows later) history strings never contain host paths or secret values.
7. Tests: `SandboxProviderContractTests<T>` abstract fixture (provision→attach→exec→logs→teardown happy path; idempotency key dedupes concurrent provisions; teardown idempotent; status transitions cover the enum; timeout honoured); implemented for Fake + LocalPodmanCompose(fake runner). `SandboxLifecycleTests` (fake clock: TTL expiry → reaper; retried teardown with jittered backoff asserts retry count + final Destroyed; failed provision never Running). `GoldenPolicyTests` pin `TestData/golden/*` byte-exact. `VendorStubTests` assert typed failures + capability honesty (Railway `Attestation.None`, enclave `Unverified`).
8. Register project + test project in `OmpOS.slnx` + `OmpOS.Linux.slnf` (own these two files this wave; no other agent runs). No new NuGet packages needed — if you believe otherwise, STOP and report.
