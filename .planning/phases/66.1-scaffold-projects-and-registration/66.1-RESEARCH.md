## Architecture Patterns
- One commit per project covering csproj, test csproj, slnx, slnf, LayerMap, ArchitectureTests reference, lock files, docs row (`09:9-12`, `09:110`); the scaffold may batch all 40 in one commit if the relock is single.
- L1 for shared contracts (`Resilience`, `Cowork.Abstractions`, `ComputerUse.Abstractions`) so L2 projects avoid same-layer tuples; process spawning only in `Harness.*` names (`09:112-113`).
- Real implementation behind an L1 interface, stores take `NpgsqlDataSource` from the host (R14) instead of a new edge.

## Pitfalls
- Registration spread over commits leaves a project invisible to the gate (`fd8f335` vs `3171ee8`, `09:9-10`).
- A project missing from `Autonogrammer.Linux.slnf` is never built, tested or formatted (`09:23`).
- `CI=true` forces locked mode and the relock fails: unset `CI` or pass `-p:RestoreLockedMode=false` (`09:26`).
- Uppercase TODO, FIXME, HACK or XXX markers in first-party `.cs`, `.csproj`, `.props` files fail the gate (`09:43`); `#pragma` or `SuppressMessage` needs a `SUP-nnn` row (`09:31`).
- `Windows` and `MacOS` ComputerUse projects must build warning-free on Linux (manifest rows 12, 13: plain `net10.0`, `DllImport` only).
- PuppeteerSharp brings `Microsoft.Extensions.Logging` 8.0.0 transitively; the central pin 10.0.13 must override it (`00-scaffold-manifest.md:25`).
- The Android lock needs a relock for a new transitive project (`Dispatch.Client`); without the Android workload the host may not run it [INFERENCE].
- A repository-wide `GateParityTests` compares the script lists of `bootstrap.sh` and `ci.yml`; the scaffold adds no gate step (`09:46`).
