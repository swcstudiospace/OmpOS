## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tool/model -> ArtifactService | model-supplied bytes, titles, versions are untrusted input |
| ArtifactService -> IArtifactStore | stored bytes are untrusted on read; hash re-check is the control |
| export -> filesystem | exported names and content reach the user disk; sanitised names are the control |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
