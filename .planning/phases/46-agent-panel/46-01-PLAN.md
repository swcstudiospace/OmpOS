# Phase 46 Plan 01: The Default Cursor-Style Agent Panel

Inputs: `46-CONTEXT.md` (with its amendments table), `46-UI-SPEC.md`, ROADMAP.md Phase 46 (criteria 1 to 8 as rewritten for DR-1), REQUIREMENTS.md (AL-09 to AL-12, AL-19), `docs/decisions/ADR-0012-agent-loop-plugins.md` (Update 2026-10-26).

This record lists the units that were built. It was written after the work, from the commits and the files. DR-1 governs: the default Cursor-style Agent Panel is the agent panel. It has a session rail (the Agents sidebar), a thread, a composer, the header chips and a one-line plugin connection row directly under the header. It has no inspector and no second agent surface. The inspector tabs of the first specification (Pipeline, Context, Steering history) were not built as regions; their content moved to the Kanban card (Phase 39).
