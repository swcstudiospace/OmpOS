Goal: the web head sends prompts and SSE only to the configured origin (or loopback override), and the SSE client and parser stay bounded.

## Tasks

- Verify: a non-loopback `apiBaseUrl` override throws naming `apiBaseUrl`; a loopback override is accepted; the configured value path is unchanged.
