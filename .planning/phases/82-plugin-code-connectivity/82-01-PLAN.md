<objective>
Prove plugin code-connectivity is transport-independent (RPC-82-1 to RPC-82-3, ADR-0038 D5): extend the RPC launch path so the one shared `OmpLaunchPlan` reaches an RPC-launched omp exactly as it reaches an ACP-launched one — plugin `-e` entries, `ConfigOverlayWriter --config`, bundle skills overlays, Cowork/isolation contributions, and MCP servers — or record each unprovable point as a transport difference in OQ-526 with its refusal intact.
