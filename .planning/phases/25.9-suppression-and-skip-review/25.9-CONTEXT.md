## Decisions

- D1 (every SUP row has a decision): each of the 156 rows now has one: kept with a recorded justification, or fixed at the cause. 20 were fixed and 136 kept. The decision table of `quality-bar.md` section 2 has one row per SUP id (SUP-001 to SUP-156); the full text of each decision is the SUP row of `docs/open-questions.md`. 24 rows (SUP-133 to SUP-156) were added for sites that appeared after 2026-10-22 and were kept: 2 `CA2000` suppressions and 22 skip-type markers.
- D2 (what was fixed): 18 class-level `CA2007` and `MA0004` suppressions in test classes were removed without changing an `await` (every test project is an executable, where neither rule reports, and 196 other test files await without `ConfigureAwait` and carry no suppression). `GuardTests` (`tests/Autonogrammer.Api.IntegrationTests`) uses `Assert.ThrowsAny<Exception>` instead of a try/catch under a `CA1031` pragma, as `quality-bar.md` records; that file is not among the 22 files of `38086c8`. `CapturingLogger<T>.LogEntry` became `internal`, which removed its `CA1515` suppression. One `CA1031` pragma was fixed (SUP-050). Together: 20 rows fixed (19 `SuppressMessage`, 1 pragma).
- D3 (what was kept): `CA1031` catch-alls sit at failure boundaries whose contract is "never throw" or "preserve the cause" (background loops, fail-closed permission paths, best-effort cleanup, readiness probes). `CA1515` suppressions are public types xUnit discovery or fixture generics require. `CA2000` suppressions mark disposal ownership handed to the object under test. `CA5394` is seeded or injected `Random`; `CA2100` is a SQL identifier the helper generates; `VSTHRD003` is a test-owned gate task. Skips fire only where the tool, OS, privilege or live opt-in is absent.
- D4 (the `.editorconfig` overrides): none removed. `CA1303 = none` (all C# files) stays because the product ships English-only text and no localization requirement exists. `CA1707`, `CS1591` and `CA1062` stay for `tests/**.cs` only: test names use `Subject_Behaviour`, test projects publish no API, and test helpers take trusted arguments. The justification is SUP-001 to SUP-004 and the table. The overrides are still at `.editorconfig` lines 395 and 398 to 400.
- D5 (the counts reconcile with a stated scope): the counts table names the scope of each count. Scope of the suppression counts: first-party `.cs`, `.razor` and `.axaml` files and `.editorconfig`, excluding `plugins/`, `bin`, `obj`, `TestResults`, `.planning`, `docs`, `TestData`, `output`, `node_modules` and `.nuget`; the scanner `SuppressionScanner` has the same scope. `25.1-FINDINGS.md` section 10 had left the difference between the 2026-10-22 counts and the codebase audit's counts unreconciled (the earlier audit had counted `docs/`, `services/` and `tools/`); stating the scope closes it.
- D6 (the ledger is a gate): `SuppressionLedgerTests` fails the build when a `#pragma warning disable`, a `SuppressMessage` or a `severity = none` override has no kept SUP row, or when a kept row no longer has its suppression. The scanner ignores comments, strings and generated output, and controls prove it.
- D7 (no rule excludes suppressions): no repository document forbids suppressions. The earlier audit had recorded the rule "no pragma, NoWarn, SuppressMessage, Skip or disabled tests" as a repository rule; it was a coding rule the orchestrator set for the wave units. Each occurrence was therefore a review question.
