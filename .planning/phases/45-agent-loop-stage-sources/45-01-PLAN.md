## Units built

| Unit | Folder | What it built | Main tests |
|------|--------|---------------|------------|
| U1 | `Stages/` (Ultrathink) | `UltrathinkPlanParser` and `UltrathinkStateObserver`: read the planner's session record, map it to a plan stage and a tracking stage, ignore unknown fields, degrade on a fallback, an unreadable or an oversized record. | `UltrathinkPlanParserTests`, `UltrathinkStateObserverTests` |
| U2 | `Stages/` (Swarm) | `SwarmLiveObserver`, `SwarmEventTail`, `SwarmRunTable`, `SwarmRunPhase`: read `live.json` and tail `events.jsonl`, keep a bounded run table, one child stage per subagent run and a parent with counters. | `SwarmLiveObserverTests`, `SwarmEventTailTests`, `SwarmRunTableTests` |
| U3 | `Substrate/` (gateway) | `SubstrateGateway`, `SubstrateEndpoint`, `SubstrateWire`, `SubstrateText`, `WorkspaceRepositoryResolver`: the only host-side Substrate client (`GET /healthz`, `POST /brief`, `POST /mcp`, `POST /events/query`). | `SubstrateGatewayTests`, `SubstrateTextTests`, `WorkspaceRepositoryResolverTests` |
| U4 | `Substrate/` (observer, reader, recorder) | `SubstrateStageObserver` and `SubstrateStageMapper` (health, brief, lease, ledger), `SubstrateContextReader` (shared memory, lessons, the claimed task), `SubstrateSteeringRecorder` (the `note` event with `payload.action` `steer`). | `SubstrateStageObserverTests`, `SubstrateContextReaderTests`, `SubstrateSteeringRecorderTests` |
| U5 | `Gsd/` | `GsdToolsLocator`, `GsdProcessRunner` and `GsdProcessTree` (bounded child process, tree kill), `GsdToolsClient` (cached `roadmap.analyze`), `GsdStateObserver` (phase stage), `GsdTaskContextSource` (merges phase and Substrate context). | `GsdToolsLocatorTests`, `GsdProcessRunnerTests`, `GsdToolsClientTests`, `GsdStateObserverTests`, `GsdTaskContextSourceTests` |
| U6 | `Sessions/` | `AgentSessionRegistry` (the `ISessionCatalog` implementation), `AgentSessionStateFile` (atomic JSON with quarantine), `AgentSessionRecord`, `AgentSessionIds`, `AgentSessionLimitException`. | `AgentSessionRegistryTests` |
| U7 | `Stages/` | `CompositeStageSource` and `StageEventDeduper`: one merged, deduplicated stage event stream over all sources, with one Degraded event for a child that throws. | `CompositeStageSourceTests`, `StageTextTests` |
