## Differences between the criteria text and the code

- Criterion 5 says a Degraded stage when the Substrate is unreachable. The recorder returns `Skipped` with a reason and logs at debug level; the Substrate stage itself becomes Unavailable or Degraded through the observer (D45-8). Both are covered by tests; the link between them in the panel is Phase 46.
- The Substrate note event carries `Outcome = queued` in the code read for this record (`SubstrateSteeringRecorder`). Phase 49 changed the steering path; whether the recorded outcome word changed with it was not checked here.
