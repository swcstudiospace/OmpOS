# Phase 2 · Plan 05 — Sessions: repository, service, projection (SESS-01..03)

## Objective

Append-only Seq-numbered session log with repository contract fixture, one-active-prompt enforcement (`PromptInFlight`), and a pure harness→StreamEvent/UiBlock projection proven by replay equality.

## Tasks

1. `ISessionRepository`: `Task<Session?> GetAsync(string id, CancellationToken)`, `Task SaveAsync(Session session, CancellationToken)`, `Task AppendAsync(string sessionId, StreamEvent evt, CancellationToken)`, `IAsyncEnumerable<StreamEvent> ListFromSeqAsync(string sessionId, long fromSeq, CancellationToken)` (`fromSeq` inclusive). `InMemorySessionRepository`: thread-safe (`ConcurrentDictionary` + per-session `object` append lock); Seq assignment atomic and monotonic per session; unknown session on Append throws `KeyNotFoundException`.
2. `SessionRepositoryContractTests<T>` abstract fixture (in this test project, public so the Phase 3 sandbox-adjacent repositories could reuse the pattern): get-missing-null; save+get round trip (full Session equality); append assigns Seq 1,2,3… under concurrency (10 parallel appends → exactly 1..10, no gaps, no dupes); ListFromSeq(2) returns 2..; ListFromSeq(0) returns all; ListFromSeq past end yields empty.
3. `SessionService`: ctor `(ISessionRepository, TimeProvider)`; `Task<Session> CreateAsync(string ownerId, CancellationToken)`; `Task SubmitPromptAsync(string sessionId, string prompt, CancellationToken)` — loads session, if `SessionStatus.Running` or a prompt is in flight throws `OmpOSError(ErrorCode.PromptInFlight)` (never queues silently); sets Running, appends envelope ack; `Task RecordCompletionAsync(string sessionId, SessionStatus final)` guard rejects transition from non-Running with `OmpOSError(ErrorCode.InvalidSessionState)` (check ErrorCode enum for the actual member; if absent use the closest existing code and add a row to the plan's deviations — do NOT modify Contracts); steer/follow-up: `SubmitSteerAsync`/`SubmitFollowUpAsync` distinct methods, exempt from PromptInFlight, policy documented in XML docs (queued until current prompt settles).
4. `HarnessEventProjection` static pure class: `ProjectionState Fold(ProjectionState state, HarnessEvent evt)` and `IReadOnlyList<StreamEvent> ToStreamEvents(long startSeq, string sessionId, string correlationId, HarnessEvent evt)` — TextDelta→TextDeltaPayload, UiBlockEvent→UiBlockPayload, Error→ErrorPayload, Completed→CompletedPayload, others (Thought/ToolCall/ToolCallUpdate/PermissionRequest/Plan) fold into `UnknownPayload` with `OriginalKind` set to the harness kind name (contract: nothing drops silently); UI state = ordered list of UiBlock + streaming text buffer per message.
5. Tests: `InMemoryRepositoryFixture` (implements contract fixture for in-memory impl); `SessionServiceTests` — PromptInFlight rejection while Running, allowed after completion; steer during Running accepted; repository missing session → OmpOSError; completion from Idle rejected; `ProjectionReplayTests` — fold a fixed 23-event script (mixed kinds incl. one malformed-ish Unknown) → serialize StreamEvent log → replay fold from empty → identical UI state (record equality); folding is deterministic (no wall clock inside — timestamps injected as arguments).
