# Phase 2 · Plan 04 — Real omp RPC JSONL client (HARN-05)

## Objective

JSONL-over-stdio RPC client implementing the `ready` handshake, `negotiate_protocol` v2 with `rpc_chunk` reassembly, id-correlated out-of-order responses, prompt admission vs `prompt_result` completion, abort commands, concurrent stderr drain; replay + live smoke tests.

## Wire facts (02-RESEARCH.md VF-2 — authoritative)

First frame `{"type":"ready","protocolVersion":1,"supportedProtocolVersions":[1,2],"maxFrameBytes":1048576,"maxReassembledFrameBytes":67108864}`. Command `{type, id?, ...}` → response `{"id","type":"response","command","success","data"|"error","code?"}`. After v2 negotiation, oversized inbound frames arrive as `{type:"rpc_chunk",chunkId,index,count,byteLength,data(base64 utf8)}` — reassemble by (chunkId, index), concat, JSON-parse. Unsolicited frames: `advisor_cost_changed`, `available_commands_update` (tolerate; ignore-unknown rule). `prompt` response `success:true` = admitted (`data.agentInvoked:false` = local command, no prompt_result follows); completion = `{type:"prompt_result",id,agentInvoked,status:"completed"|"aborted"|"error",error?,sessionSettled}`. `abort`, `abort_and_restore_queue` exist. Close stdin → drain → exit 0; client MUST keep reading stdout after closing stdin. Fixture: `.planning/phases/02-core/frames/rpc-out.ndjson`.

## Tasks

1. `OmpRpcFrames.cs`: `ReadyFrame(ProtocolVersion, SupportedProtocolVersions[], MaxFrameBytes, MaxReassembledFrameBytes)`, `RpcCommand` base `{Type, Id?}` with `NegotiateProtocolCommand`, `GetStateCommand`, `PromptCommand(Message, Images?, StreamingBehavior?)`, `AbortCommand`, `AbortAndRestoreQueueCommand`, `UnknownCommandProbe`; `RpcResponse(Id, Command, Success, JsonExtensionData Data, string? Error, string? Code)`, `RpcChunkFrame(ChunkId, Index, Count, ByteLength, string Data)`, `PromptResultFrame(Id, AgentInvoked, Status, RpcPromptError? Error, JsonExtensionData SessionSettled)`, `UnknownFrame(Type, JsonExtensionData Rest)`. `OmpRpcJsonContext` source-generated; every inbound frame parses into a `{Type, ExtensionData}` envelope first, then typed dispatch — unknown types must NOT throw.
2. `RpcChunkAssembler`: stream of frames in → reassembled logical frames out; caps enforced (1 MiB physical input line, 64 MiB reassembled — overflow → `MalformedFrameHarnessException`); out-of-order index delivery tolerated (buffer until complete); duplicate chunkId → MalformedFrame.
3. `OmpRpcProcess`: spawn `[ompPath, "--mode", "rpc", "--no-ui", "--cwd", cwd]` (path injectable), newline JSONL stdout reader producing logical frames (through assembler), stderr drain task (never blocks stdout loop), write-side lock; graceful close = close stdin, keep reading until exit (timeout → kill process group); exit code surfaced.
4. `OmpRpcSession : IOmpSession`: handshake = wait `ready` (timeout → HandshakeTimeout) then send `negotiate_protocol {protocolVersion:2}`; command dispatcher matches responses by `id` strictly (concurrent in-flight commands fine); `SubmitPromptAsync` = `prompt` admission + async enumeration of stream frames until `prompt_result` with same id; `agentInvoked:false` → immediate Completed; status error → `ErrorEvent` then Completed("error"); `CancelAsync` = `abort`; capabilities: from `get_state` data (`model.id`, `model.provider` keys exposed).
5. `OmpRpcClient` composition root + `OmpRpcClientOptions{OmpPath?, Cwd, HandshakeTimeout, CommandTimeout}`; startup version probe `omp --version` parsed into `(int Major, int Minor, int Patch)` exposed for the client's pin check.
6. Tests: copy `rpc-out.ndjson` into `TestData/frames/`. `RpcFrameReplayTests`: scriptable in-memory process feed replays the fixture — assert ready parse, negotiate response data `{"protocolVersion":2}`, get_state id correlation, unknown-command `success:false` surfaces `RpcCommandException`-equivalent typed error, unsolicited frames ignored. Add a synthetic >1 MiB `get_state` response split into 8 `rpc_chunk` frames delivered out of order (shuffle indexes) → reassembles. `RpcLiveSmokeTests`: skip when omp absent; spawn `omp --mode rpc --no-ui --cwd <repo>`, ready→negotiate v2→`get_state`→close stdin→exit 0 asserted. NO prompt.
7. Register in `OmpOS.slnx` + `OmpOS.Linux.slnf`; locks regenerate.
