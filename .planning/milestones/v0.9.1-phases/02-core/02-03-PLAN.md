# Phase 2 · Plan 03 — Real ACP v1 client (HARN-04)

## Objective

ACP v1 JSON-RPC 2.0 client over newline-delimited stdio (source-generated STJ), passing replay tests from captured frames and a live smoke against installed `omp acp`, skipped when omp is absent.

## Wire facts (02-RESEARCH.md VF-1 — authoritative)

Requests: `{"jsonrpc":"2.0","id":N,"method":"...","params":{...}}`; notifications have no `id`. Initialize result carries `agentCapabilities{loadSession,mcpCapabilities{http,sse},promptCapabilities{embeddedContext,image},sessionCapabilities{list,fork,resume,close}}` and `agentInfo{name,title,version}`. `session/new{cwd,mcpServers}` → `{sessionId, configOptions[]}` (configOptions opaque — use `[JsonExtensionData]`). Frames in `.planning/phases/02-core/frames/acp-{in,out}.ndjson`.

## Tasks

1. `AcpFrames.cs`: records for `AcpRequest<T>(long Id, string Method, T Params)`, `AcpNotification(string Method, object Params)`, `AcpResponse<T>(long Id, T? Result, AcpError? Error)`, `AcpError(long Code, string Message)`, and typed params/results: `InitializeParams(ProtocolVersion, ClientCapabilities{Fs{ReadTextFile,WriteTextFile}})`, `InitializeResult(ProtocolVersion, AgentInfo{Name,Title,Version}, AuthMethod[], AgentCapabilities)`, `NewSessionParams(Cwd, McpServer[])`, `NewSessionResult(SessionId, JsonExtensionData ConfigOptions)`, `PromptParams(SessionId, Content[])`, `PromptResult(StopReason)`, `CancelParams`, `LoadParams`, `RequestPermissionRequest`, `FsReadTextFileParams/Result`, `FsWriteTextFileParams`. `AcpJsonContext`: source-generated `JsonSerializerContext` covering the envelope + payloads; unknown-member tolerant options (`UnmappedMemberHandling` default skip), `DefaultIgnoreCondition = WhenWritingNull`, camelCase policy.
2. `AcpStdioTransport : IAcpTransport`: `ProcessStartInfo` argv = `[ompPath, "acp"]` (path injectable, default resolve `omp` from PATH), `RedirectStandardInput/Output/Error = true`, no shell; UTF-8 no-BOM; newline-delimited write with `\n`; background stderr drain task feeding an `IObservable<string>`-shaped callback (or `Channel<string>`); dispose kills process group; handshake read timeout (default 10 s) → `HandshakeTimeoutHarnessException`; process exit → `DisconnectedHarnessException`; malformed JSON line → `MalformedFrameHarnessException` (frame content in message, first 2 KiB only).
3. `AcpAgentSession : IOmpSession` — method map: create→`initialize`+`session/new`; resume→`session/load`; SubmitPromptAsync→`session/prompt` streaming `session/update` notifications (`agent_message_chunk`→TextDelta, `agent_thought_chunk`→Thought, `tool_call`→ToolCall, `tool_call_update`→ToolCallUpdate, `plan`→Plan) and terminal `stopReason`; cancel→`session/cancel` + `$/cancel_request`; dispose→`session/close` then transport close. `session/request_permission` agent→client request answered via `AcpApprovalPolicy` hook: **default policy denies** (responds `{"outcome":{"outcome":"deny"}}`); policy may deny earlier but can never grant beyond the configured allowlist (assert in test). `fs/read_text_file`/`fs/write_text_file` only when client capabilities flags were set (they are false here → agent requests answered with protocol error, tested).
4. `OmpAcpClient` composition root: `IOmpSession CreateSession(AcpClientOptions)`; `AcpClientOptions{OmpPath?, HandshakeTimeout, RequestTimeout}`; capability dictionary exposed from initialize result.
5. Tests: copy `.planning/phases/02-core/frames/acp-in.ndjson` + `acp-out.ndjson` into `TestData/frames/`. `AcpFrameReplayTests`: in-memory scriptable transport (loopback pair from ContractTests) fed `acp-out.ndjson` lines; assert request frames serialize byte-identical to `acp-in.ndjson` (modulo whitespace), capability dictionary matches, `configOptions` round-trips as extension data. `AcpLiveSmokeTests`: `[SkippableFact]` (Shouldly.SkippableFact or xunit `Skip.If`) — skip when `command -v omp` fails; spawn real `omp acp`, initialize + session/new + session/close; assert `agentInfo.name == "omp"`, capabilities flags true, session id non-empty. NO prompt is sent.
6. Register project + test project in `OmpOS.slnx` + `OmpOS.Linux.slnf`; lock files regenerate.
