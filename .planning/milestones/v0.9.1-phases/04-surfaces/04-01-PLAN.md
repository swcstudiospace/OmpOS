3. `SessionViewState` enum: LoadingHistory, Empty, Streaming, AwaitingApproval, RecoverableError, FatalError, Reconnecting, Offline, Success (single source for announcements).
4. `wwwroot/styles/ompos.css`: WCAG AA contrast token pairs as CSS custom properties, visible focus rings (`:focus-visible`), `prefers-reduced-motion` media query, ≥44px target sizes.
5. Tests (`tests/OmpOS.UI.Tests`, bUnit + xunit.v3): `UiBlockRendererTests` — every block variant renders expected markup (markdown text, code+copy affordance, tool-call status card, permission options verbatim, plan panel, diff placeholder, error, A2UI subset, unknown collapsed); `ReplayTreeTests` — fold the 23-event fixture (copy the fixture family from `tests/OmpOS.Sessions.Tests` shape; if that fixture is internal, re-declare the same events) → identical `UiTree` rendered twice + re-render equality; unknown event shapes (array/string/number/null payload roots) never throw and never blank the view; `StreamingStateTests` — state transitions + stop/retry affordances + scroll-pause flags; `AccessibilityTests` — keyboard handlers, aria-labels present on icon buttons, aria-live region exists, focus styles referenced, reduced-motion rule present in bundled CSS.
6. Register RCL test project in `OmpOS.slnx` + `OmpOS.Linux.slnf` (you own both files this wave). No new packages (bunit, Verify.XunitV3, xunit.v3, Shouldly all pinned). If a package seems missing, STOP and report.
