# Phase 4 Surfaces: Security Verification

**Verdict: SECURED_WITH_ACCEPTED_RISK. `threats_open: 0`, `threats_accepted: 1`.** Seven rows are MITIGATED. P4-06 stays PARTIAL in the table and is accepted by the owner (decision 2026-10-21). Its sole input is MarkdownRenderer output, produced with raw HTML disabled, a link and image scheme allowlist, and a CSP without inline script. No row is OPEN.

Changes since the previous audit:
- P4-04 (`img-src`) is MITIGATED. The policy is now `img-src 'self' data:`, and remote markdown and A2UI images render as links, never as `img`.
- P4-01 (`apiBaseUrl`) is MITIGATED in this pass: the scheme and loopback tests (`FtpSchemeOverrideIsRejected`, `JavaScriptSchemeOverrideIsRejected`, `FileSchemeOverrideIsRejected`, `PlainHttpToNonLoopbackHostIsRejected`, `NonLoopbackHttpsIsAccepted`, `LoopbackHttpVariantsAreAccepted`) now exist and were read.
- P4-03 (`connect-src`) is MITIGATED in this pass. `VercelConfigConnectSrcAllowsOnlySelfAndLoopbackHttp` pins the origin class to `'self'` or loopback `http:`. `https://localhost:5001` is gone.
- P4-05 (image scheme allowlist) is MITIGATED under a new test name. The previous `ImageUrlsAreSchemeAllowlisted` no longer exists; `OnlyInlineRasterImagesRenderImg` covers it, including the `data:image/svg+xml` row that was previously untested.
- P4-06 (`MarkupString`) is PARTIAL with changed facts. A single `MarkupString` sink now exists, fed by the sanitizer. Owner disposition 2026-10-21: accepted the sanitized sink; the row stays PARTIAL and counts in `threats_open`.
- P4-07 (approval path) is MITIGATED in this pass by owner decision 2026-10-21: the two domain methods are `internal`, and the only callers are in `OmpOS.Sessions.Tests`.
- Item 8 (`prompt_accepted` as a user turn, rendered as escaped text) is verified in code. It is not a register row; see P4-06.

Scope note: the approval path (e) is absent from every HTTP route and from the UI. The domain approval methods are `internal` in `OmpOS.Sessions` (changed in this pass), so only `OmpOS.Sessions.Tests` can call them.
