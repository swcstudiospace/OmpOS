# Phase 3 Platform: Security Verification

**Verdict: SECURED. `threats_open: 0`.** All thirteen rows are MITIGATED. Four rows moved from OPEN or PARTIAL in the previous audit:

## Status rules

- **MITIGATED**: code reference at file:line, and a named test that exercises the behaviour.
- **PARTIAL**: code present, but a named branch or behaviour has no test.
- **OPEN**: no mitigation for part of the threat, or the code makes the forbidden claim.
- **threats_open** = count of OPEN plus PARTIAL items.

## Observations (not counted)

- **O-1 Unbounded captured output. Resolved.** Each stream is now capped at 1 MiB and marked `Truncated` (`src/OmpOS.Sandbox/ProcessRunner.cs:39`, `:180-191`; `tests/OmpOS.Sandbox.Tests/ProcessRunnerOutputCapTests.cs:26`). Removed from the open list.
- **O-2 Secret refs are validated, never injected.** `SecretRefs` is referenced only at `LocalPodmanComposeProvider.cs:436` and `:441`. With `AllowHostSecrets=true` the secrets are dropped without an error, so no code claims they were delivered. Either inject them or reject a non-empty `SecretRefs` in the Podman provider.
- **O-3 Compose file holds environment values in /tmp.** `WriteComposeFileAsync` (`LocalPodmanComposeProvider.cs:320`, `File.WriteAllTextAsync`) writes with no explicit file mode. The file carries `Spec.Environment` verbatim (`GenerateComposeFile`). Default permissions are probably world-readable on Linux `[INFERENCE: umask 022]`. This was never a register row and is not counted. Write with mode 0600, or pass secrets through the environment of the `podman-compose` process rather than the file.
- **O-4 Harness process spawns.** `OmpOS.Harness.Rpc` (`OmpRpcProcess.cs:58-62`, `OmpVersionProbe.cs:27`) and `OmpOS.Harness.Acp` (`AcpStdioTransport.cs:181`) also use argv-only `ArgumentList`, but no test covers those spawns. They sit outside the `IProcessRunner` item.
- **O-5 Host environment inheritance.** `ProcessRunner.CreateProcess` adds the spec's environment on top of the parent's, so host variables reach child processes. Consider clearing the environment and passing only the spec.
- **O-6 Enclave quote field echoes the nonce (new).** `DefaultAttestationBoundary.cs:13` sets `Quote = nonce.ToArray()` with `Verdict = Unverified`. The bytes are not a TEE quote. A consumer that reads `Quote` without checking `Verdict` could mistake them for one. Suggested: return `Quote = null` while no verifier is wired. Not counted: the verdict is explicit and the brief accepts the Unverified result.
- **O-7 Test double in production assembly (new).** `src/OmpOS.Sandbox/FakeSandboxProvider.cs:150-151` yields `"Executed: ..."` and `ExitCode = 0` for every exec. No file under `services/` or `apps/` references `FakeSandboxProvider` (grep). Not counted. It is the same success-shaped pattern as P3-08, so keep it out of host registration.
