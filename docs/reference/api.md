# HTTP API

Status: Built (session, run, catalogue, change and source routes are mapped and in the OpenAPI document); Partial (providers, workspace settings and cloud routes are implemented and tested, and their registration in `Program.cs` is part of the integration step: check `docs/api/openapi.json` for what a build exposes)

Last verified: 2026-10-28

Applies to: v0.15.0

`services/OmpOS.Api` is an ASP.NET Core host. It serves the web head and is the control plane for cloud agents. Every route except health and `GET /source` (and, in Development only, the OpenAPI document and the reference UI) needs an authenticated caller: the API verifies bearer tokens at its boundary, and a session belongs to its owner (another caller gets 404). The in-memory harness and the development principal are refused outside the Development environment.

The machine-readable contract is [`docs/api/openapi.json`](https://github.com/swcstudiospace/OmpOS/blob/main/docs/api/openapi.json) (OpenAPI 3.1, generated by the API build; `GET /openapi/v1.json` serves the same, anonymously only in Development). On GitBook it is registered as a URL source: [Publish the docs with GitBook](../runbooks/gitbook-publish.md).

## Sessions and runs

| Route | What it does |
|---|---|
| `POST /sessions`, `GET /sessions`, `GET /sessions/{id}` | Create, list and read sessions. |
| `POST /sessions/{id}/prompts` | Submit a prompt. |
| `GET /sessions/{id}/events` | The session's server-sent event stream. `id:` is the sequence number; resume with `Last-Event-ID` or `?since=`. A terminal `completed` or `error` ends it. |
| `POST /sessions/{id}/runs`, `GET /sessions/{id}/runs/{runId}`, `.../output`, `POST .../cancel` | Hosted run contract. Admission is synchronous: a conflicting run lease answers 409. |
| `GET /sessions/{id}/tool-approvals`, `POST /sessions/{id}/tool-approvals/{requestId}` | List and decide tool approvals. |
| `POST /sessions/{id}/steer` | Send a message to the active turn, now or as a queued follow-up. |
| `GET /sessions/{id}/config-options`, `PUT .../config-options/{optionId}`, `GET .../commands` | The model, mode and thinking options and the slash commands the engine advertises. Changing an option needs a live engine; mid-turn it answers 409. |
| `GET /sessions/{id}/stages`, `GET .../context` | Stage events and the task context. |
| `GET /sessions/{id}/changes`, `POST .../changes/{path}/accept`, `POST .../changes/{path}/reject` | The change review. A reject restores the text before the edit and only when the file still holds the agent's text. |

## Catalogue and board

| Route | What it does |
|---|---|
| `GET /board` | The Kanban board built from the caller's sessions. |
| `GET /sessions/{id}/card-details` | What the Substrate knows about the session behind a card. |
| `POST /sessions/{id}/close`, `.../reopen`, `.../resume` | Close, reopen, or settle the orphaned run of a lost session. |
| `GET /workspace` | The workspace name, folder name and plugin check. |
| `GET /events` | Catalogue, status and stage events of the caller's sessions, streamed. |

## Providers (Partial: registration is part of the integration step)

| Route | What it does |
|---|---|
| `GET /providers?region=&kind=&search=` | The provider catalogue with the configured state (no secrets). Regions: `europe`, `united-states`, `china`, `global`, `local`. Kinds: `api`, `aggregator`, `coding-plan`, `local`. |
| `GET /providers/{id}` | One provider. |
| `PUT /providers/{id}/credential` | Store a key through `omp auth import`. 403 unless `Providers:AllowCredentialWrite` is on; 409 for rows the operator manages by environment variable. |
| `PUT /models/default`, `POST /providers/custom`, `DELETE /providers/custom/{id}` | Change omp's default model or custom endpoints. 403 unless `Providers:AllowConfigWrite` is on. |
| `POST /providers/{id}/test` | A live reachability check to public addresses only. Answers `skipped` unless `Providers:AllowLiveTest` is on. |

## Workspace settings (Partial)

All `GET`, read-only: `/workspace/conventions`, `/settings/runtime`, `/settings/plugins`, `/settings/network`, `/hooks`, `/automations`, `/workspace/tree?path=` and `/workspace/file?path=` (UTF-8 text up to 1 MiB, secret files excluded). Every workspace route answers 404 `workspace_not_configured` unless `Api:Workspace:Root` is set; `Api:Workspace:Owners` restricts who may read it.

## Cloud agents (Partial: control plane against fakes; `Cloud:Enabled` is false by default)

| Route | What it does |
|---|---|
| `POST /cloud/agents`, `GET /cloud/agents`, `GET /cloud/agents/{id}`, `DELETE /cloud/agents/{id}` | Create (202), list, read and delete a cloud agent bound to repositories, a branch and secret references. |
| `POST /cloud/agents/{id}/prompts`, `.../cancel`, `.../stop`, `.../wake` | Prompt, cancel, stop and wake the worker. |
| `GET /cloud/agents/{id}/events` | The agent's event stream. |
| `POST /cloud/agents/{id}/pull-request` | Open a pull request from the agent's branch. |
| `GET/PUT/DELETE /cloud/secrets/{name}`, `GET /cloud/secrets` | Secret references (values are write-only). |
| `GET /cloud/limits` | The caps in force. |

See [Cloud agents on Railway](../runbooks/cloud-agents.md) for statuses, errors and what is blocked.

## Source offer

`GET /source` needs no sign-in and returns the licence, the source URL, the exact revision and the version, as AGPL section 13 asks of a network service: [Licensing](../licensing.md).

## Health

`GET /health/live` and `GET /health/ready` are anonymous. The API reference UI (Scalar) is served only in Development.
