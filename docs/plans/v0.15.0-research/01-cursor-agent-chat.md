# R-CURSOR-AGENT: Cursor agent, chat, context and editing surface (researched 2026-10-27)

Source of truth: Cursor docs and help markdown (cursor.com/docs/*.md, cursor.com/help/*.md, cursor.com/docs/release-notes.md, index at https://cursor.com/llms.txt). Latest release seen: Cursor 3.27 (release notes). Fit column is a guess from docs/plans/ade-harness-plan.md, docs/quality/cursor-parity-audit-2026-10-26.md and docs/settings-parity.md, plus the src/OmpOS.Harness.* project list; marked [INFERENCE] where it is my reading. Fit vocabulary: library-exists (an OmpOS.Harness.* library or presentation model exists, even if no head wires it), needs-ui, needs-engine (omp or the ACP bridge must provide it), needs-cloud (hosted API and Railway), omit-no-accounts (Cursor account, billing, team dashboard or Cursor-hosted service).
