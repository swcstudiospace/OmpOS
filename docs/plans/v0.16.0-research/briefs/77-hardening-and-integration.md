# Brief 77: Hardening, documentation, parity audit and integration (ADR-0037 D14)

Names are post-rename (Autonogrammer becomes Autonogrammer); the repo on disk still uses Autonogrammer, so `Autonogrammer.ArchitectureTests` is `Autonogrammer.ArchitectureTests` there. No ADR of its own: ADR-0037 D14 (parity audit, registries), research report [09](../09-project-recipe-and-conventions.md) sections 2, 5 and 7 (decision D2: `VersionPrefix` bumped once, at the end), [rebrand runbook](../../../runbooks/rebrand-autonogrammer.md) sections 3 to 5, and ADR-0030 to ADR-0036 for the owner actions. This is the last phase: it adds no feature. Index row 77 of [00-index.md](00-index.md) is the only place that names it.

## Goal

After phases 67 to 76 have landed and the rename (phase 66) is applied, bring milestone v0.16.0 to a shippable state: one version bump, final documentation, a parity audit that cannot contain an empty row, a written security review and accessibility pass over the new surfaces, the full gate, integration with the other line of work, a PR, and the list of actions only the owner can do. Not delivered: any live run (OD-07 is not approved; no Supabase, no Railway), Windows or macOS runs, a release tag, any rename outside the repository.

## Failure and stop states

- A High finding with no fix in reach: the phase it belongs to is not merged and this phase stops; it is not downgraded to get the gate green, and a default-off flag is not a mitigation.
- Rename tool collision or `verify` mismatch (U7): stop and read the report; fix the config, never the tool or the output.
- A lock file that restores only without `--locked-mode`: the relock was incomplete; repeat U1 on a clean `obj/`.
- Gate step fails on a file this phase did not write: report the phase and commit that did; do not patch around it.
- A parity row whose test class is not found: it is PARTIAL, not MET.
