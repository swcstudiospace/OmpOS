## Owner decisions (2026-10-21, answered autonomously)

The owner delegated these decisions to the autonomous run, against the bar stated in the Notion task 3ffbc1a0c7ae8112aa70d2e15b81929f: State-of-the-Art, Enterprise-Grade, Production-Ready and Best-in-Class. Each answer is reversible by a later recorded decision.

- **OD-03 sign-in method.** OIDC bearer tokens validated by ASP.NET Core JwtBearer against a configured authority and audience. Fail-closed: production refuses to start without `Api:Auth:Authority` and `Api:Auth:Audience`, and no development principal is reachable on a production path. No public domain until an identity provider is configured. Rationale: standards-based validation with no custom credential store; HOST-02 stays enforceable because the API refuses to start unauthenticated in production. Status: decided; implemented in Phase 12. Public exposure stays forbidden until the owner configures an authority.
- **Q-VERCEL-CSP.** `connect-src` is generated at build time from one validated API origin (https, no wildcard, no path, no query), by `vercel.ts` calling `scripts/vercel/render-csp.sh`. No other origin is allowed statically. Rationale: a static list drifts from the deployed origin, and a wildcard widens the exfiltration surface. Status: decided; implemented; deployed checks wait for the production origin (Phase 14).
- **Q-APPROVAL-ADAPTER.** ACP is the adapter for approval-capable hosted runs (`session/request_permission`). RPC is kept for update recording (Phase 11) only. Rationale: ACP carries the permission request that an interactive approval resolves. Status: decided. Phase 10 outcome: the ACP bridge from the UI decision to the running session is wired and tested (commits 75bbca0 and 4196345). Production approvals stay deny by default (`AcpApprovalPolicy.DenyAll`, empty ceiling).
- **Q-PG-RETIRE.** Not retired by automation. The plain Postgres service in Ultrathink is kept, because retiring a running platform service is destructive and stays with the owner. Status: decided; kept; the owner may retire it.
- **OD-07 live RPC turns.** Approved: one bounded live RPC run of at most 10 model turns against the installed omp, for Phase 11 only. Any further live turn needs a new recorded approval. Status: approved 2026-10-21; the run completed with ten turns, all `completed` (see `docs/runbooks/evidence/omp-rpc-live-variants-2026-10-21.md`).
