## Contributing to the docs

The documentation lives in `docs/` and publishes through GitBook's GitHub Git Sync, with GitHub as the source of truth. Do not edit pages in the GitBook editor. Rules:

- Every page starts with an H1 and, in the lines after it, `Status: Built | Partial | Blocked (reason)`, `Last verified: YYYY-MM-DD` and `Applies to: vX.Y.Z`. Describe only implemented behaviour; when something is built but not exercised live, say so.
- Add a new page to `docs/SUMMARY.md`; a page may appear there once.
- Quote the `description:` in front matter.
- Do not edit `docs/reference/providers.md` by hand: it is generated by `scripts/docs/generate-providers-md.py` from the catalogue data.
- Run `bash scripts/ci/check-docs.sh` before you push. It checks the SUMMARY, orphans, links, anchors, front matter and the pinned screenshots (`AUTONOGRAMMER_RELEASE=1` makes missing screenshots an error).
