# v0.16.0 owner actions

Status: Register only. This page performs no action; each row names the owner decision, credential or human check that blocks it. The Linear register is SPE-34972 (one checkbox per item, tagged by phase).

Last verified: 2026-11-23

Applies to: v0.16.0 (phases 66 to 78), ADR-0030 to ADR-0037

## How to read this page

Each row follows the ADR-0030 form: the action and where it happens, what it is needed for, and what the product does when it is not done. "Not done" is always a fail-closed or degraded state, never a silent success. Open-question ids are in [open questions](../open-questions.md); the rename actions are in [Rebrand to Autonogrammer](rebrand-autonogrammer.md) section 5.

## Security register (phase 77)

The release security gate is [the v0.16.0 security review](../quality/v0.16.0-security-review.md). No Critical or High finding is open there (SEC-77-01, SEC-77-02, SEC-77-05, SEC-77-07 and SEC-77-08 are fixed with named regression tests). Open: SEC-77-04 (Medium, memory idempotency production composition) and SEC-77-09 (Low, erasure entry point and cache keys). An open High would keep the architecture security audit red by design; findings are never downgraded to make a gate pass.
