# Session-chat parity inventory (Phase 21)

Status: Record (inventory written for Phase 21; some rows are pending in the native head)

Last verified: 2026-10-28 (the status only; the body is a dated record and was not re-verified)

Applies to: v0.15.0

This inventory lists every session-chat feature that the Razor head (`src/Autonogrammer.UI`) renders or that the MAUI host
(`apps/Autonogrammer.App`) wires, one row per feature. The native Avalonia head must match each row with an Avalonia test.

- **Razor tests** names tests in `tests/Autonogrammer.UI.Tests` as `Class.Method`, separated by `;`. The guard
  `tests/Autonogrammer.Presentation.Tests/ParityInventoryTests.cs` fails when a row names no Razor test or when a named test is
  not found in that assembly.
- **Avalonia test** is the native test that proves the row. Each cell names tests in `tests/Autonogrammer.Native.Tests`; the shared-scenario tests are in `Parity/SharedScenarioParityTests.cs`. A cell that starts with `pending:` states the part of the row the native head does not cover.
- **Status** is the Razor coverage state. `Razor covered` means a Razor test asserts the feature. `Razor partial` means
  a Razor test covers only part of the feature; the gap is named.
- Shared scenarios are presentation-level event sequences in `tests/Autonogrammer.Parity.Support`
  (`ParityScenarios`). `SharedScenarioParityTests` renders each one through `SessionView` and checks the normalized
  blocks against the shared expectation. The normalization contract is in `ParityNormalization`.
- Rows 1 to 38 have Razor sources. Rows 39 to 44 are MAUI host features; the Razor tests named there cover the Razor
  side of the same behaviour. Row 45 is the shared user-message echo: its Razor source is the GenUi fold that both heads render. Rows 46 to 49 are the tool-result, file-edit and approval-decision blocks (contract 1.1.0) and the fold that produces them.
