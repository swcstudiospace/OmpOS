# Session-chat parity inventory (Phase 21)

This inventory lists every session-chat feature that the Razor head (`src/OmpOS.UI`) renders or that the MAUI host
(`apps/OmpOS.App`) wires, one row per feature. The native Avalonia head must match each row with an Avalonia test.

- **Razor tests** names tests in `tests/OmpOS.UI.Tests` as `Class.Method`, separated by `;`. The guard
  `tests/OmpOS.Presentation.Tests/ParityInventoryTests.cs` fails when a row names no Razor test or when a named test is
  not found in that assembly.
- **Avalonia test** is the native test that proves the row. Each cell names tests in `tests/OmpOS.Native.Tests`; the shared-scenario tests are in `Parity/SharedScenarioParityTests.cs`. A cell that starts with `pending:` states the part of the row the native head does not cover.
- **Status** is the Razor coverage state. `Razor covered` means a Razor test asserts the feature. `Razor partial` means
  a Razor test covers only part of the feature; the gap is named.
- Shared scenarios are presentation-level event sequences in `tests/OmpOS.Parity.Support`
  (`ParityScenarios`). `SharedScenarioParityTests` renders each one through `SessionView` and checks the normalized
  blocks against the shared expectation. The normalization contract is in `ParityNormalization`.
- Rows 1 to 38 have Razor sources. Rows 39 to 44 are MAUI host features; the Razor tests named there cover the Razor
  side of the same behaviour.
