## 3. Gated vs ungated split

### Ungated — executable now on Linux with throwaway services

2. **Codec fix for NEW rows only (§2a–d)**: new unkeyed commands stop writing `CommandId` as the caller key; new reads return exact `null`/key. This changes behavior only for rows written after the fix — no material legacy outcome.
