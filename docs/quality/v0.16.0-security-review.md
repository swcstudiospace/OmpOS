# v0.16.0 Security Review

Status: **Open findings; not release-ready.** This is a code review, not a penetration test.

## Purpose
This review records the milestone security delta against `docs/security/hosted-threat-model.md` (TB1–TB8). D-16 prohibits shipping with an open or accepted High or Critical finding.

## Verification
- The architecture audit tests passed before these newly recorded High findings were added; the security gate must be rerun after remediation and must fail while they remain open.
- `DefaultConfigTests` passed 15/15. Account, board, authentication and client compatibility suites passed 85/85 in focused local runs. Pairing-store tests passed 7/7 and reconnect tests 28/28; actual OS keyrings and native pairing remain unverified. A valid enabled-production Dispatch baseline remains blocked by its in-memory-store validator.
- No live model turn or external provider was used (OD-07). Two PostgreSQL test classes tagged `Category=Live` were explicitly run against a run-owned local database; this does not satisfy the final gate's Live-exclusion rule.
