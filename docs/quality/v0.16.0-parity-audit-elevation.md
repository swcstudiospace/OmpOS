# Cowork parity audit elevation (v0.16.0)

Status: Gate implemented and green. This page records how the parity gate meets the phase 66 SOTA pattern; it grades no row.

Last verified: 2026-11-23

Applies to: `scripts/docs/parity_counts.py`, `docs/parity/cowork-parity.md`, phase 77 (plans 77-02, 77-09)

## What the gate is

`scripts/docs/parity_counts.py` (Python standard library only) parses the row tables of `docs/parity/cowork-parity.md`, counts rows by first status word, and compares the counts with the summary block in the same file. `scripts/ci/check-docs.sh` runs it with `--check` on every docs gate. `CoworkAuditTests` additionally requires every MET row to name a test class that exists under `tests/`.

## SOTA states

| Concern | Behaviour |
| --- | --- |
| Explicit states | Parse, count, compare and report are separate steps; the vocabulary is exactly MET, PARTIAL, NOT-STARTED, DEFERRED, OMITTED-BY-DECISION. A bracketed qualifier after the first status word is tolerated and ignored for counting. |
| First attempt | A consistent file passes first attempt with `OK: parity counts match` and exit 0; no retry, no rewrite. |
| Fail closed | A count mismatch, an unknown status word or a missing table exits 1 and names the row. The gate never edits the audit to make itself pass. |
| Validation | Header-aware parsing; counts are derived from the row tables, never from the summary block being checked. |
| Graceful degradation | The script needs no network, no services and no third-party package; it runs identically locally and in CI. |
| Accessibility | Output is plain text, one fact per line; no colour-only signalling. |
| Operational | Run `python3 scripts/docs/parity_counts.py --check` to verify, without `--check` to print the counts block for review. CI evidence is the `check-docs` step of the `ci` workflow. |

## Evidence

- `python3 scripts/docs/parity_counts.py --check` → `OK: parity counts match` (2026-11-23, this tree).
- `bash scripts/ci/check-docs.sh` → 0 errors, 0 warnings, parity check included.
- Grades themselves live only in [the Cowork parity audit](../parity/cowork-parity.md) (51 rows: 0 MET, 23 PARTIAL, 19 NOT-STARTED, 3 DEFERRED, 6 OMITTED-BY-DECISION at last grade). Regrading a row to MET requires a named passing test class; omp-dependent rows stay PARTIAL until a live run is recorded (OD-07).

## What this page does not claim

No parity row is regraded here, no live run is claimed, and the elevation record does not close phase 75 or 76. Those close only through their VERIFICATION files.
